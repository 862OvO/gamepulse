# GamePulse 第一阶段需求

## 项目目标

使用匿名模拟游戏事件建立可复现的数据分析闭环，为数据分析、产品运营和游戏策划岗位展示业务理解与 .NET 工程能力。

## 当前范围

- 接收 JSON 格式的匿名事件批次。
- 校验必填字段、非负数值、移动方向和重复事件 ID。
- 使用 SQLite 持久化事件。
- 计算玩家数、对局数、平均时长和平均得分。
- 计算次日留存率。
- 计算开始、移动、达到目标分数和结束对局的行为漏斗。
- 提供 OpenAPI 文档、自动化测试和 CI。

## 暂不包含

- CSV 导入、报表导出和数据生成器。
- 玩家分群、活动配置和 A/B 方案对比。
- 登录、权限和操作审计。
- Blazor 数据看板及正式视觉设计。

## 验收标准

1. `dotnet build GamePulse.sln --configuration Release` 无错误。
2. `dotnet test GamePulse.sln --configuration Release` 全部通过。
3. 样例 JSON 可以被导入，重复导入会返回拒绝摘要。
4. 四个分析接口根据数据库内容返回可核验结果。
5. 仓库不包含真实玩家身份数据、密钥或本地数据库文件。
