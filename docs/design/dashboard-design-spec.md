# GamePulse 数据看板设计规范

本规范由桌面端与移动端概念图提炼，用于约束 Blazor 实现，避免后续页面风格漂移。

## 概念基准

- 桌面端：`dashboard-desktop-concept.png`（1536 × 1024）
- 移动端：`dashboard-mobile-concept.png`（853 × 1850）
- 产品类型：真实数据工具，不采用营销页结构。

## 信息架构

1. 侧边导航：总览、留存分析、行为漏斗、数据导入。
2. 页面标题与数据范围控制。
3. 四项核心指标：匿名玩家、游戏局数、平均时长、平均得分。
4. 核心趋势与次日留存。
5. 行为漏斗。
6. 最近导入及 JSON 导入操作。

| 用途 | 值 |

字体使用系统中文无衬线字体，标题 28–32px，区块标题 18–22px，控件与图表标注 13–16px。阴影只用于侧栏和浮层，数据区以细边框和留白建立层级。

## 容器和响应式规则

- 桌面端为固定侧栏加开放式主画布，不使用统一的卡片矩阵。
- 四项指标保持一条横向数据带；移动端改为两列两行。
- 桌面漏斗为横向阶段带；移动端为纵向阶段轨道。
- 小于 `900px` 时侧栏变为抽屉；小于 `640px` 时所有分析区纵向排列。
- 所有按钮至少 44px 高，页面不允许横向滚动。

## 可见文案锁定

首屏允许出现：`GamePulse`、`总览`、`留存分析`、`行为漏斗`、`数据导入`、`运营数据总览`、`全部样例数据`、`匿名玩家`、`游戏局数`、`平均时长`、`平均得分`、`核心趋势`、`次日留存`、`最近导入`、`导入 JSON`。

指标与图表只展示 API 返回的真实值。概念图中的趋势日期属于构图示意，代码实现必须使用样例事件实际日期。

## 图标与交互

- 图标统一使用 24px 以内、约 1.8px 描边的线性 SVG。
- 侧栏当前项以橙色左边线和深蓝浅阶背景标识。
- 菜单、导入按钮、文件选择、错误提示和成功提示均提供键盘焦点状态。
- 动效仅用于抽屉、数据载入和导入结果反馈，并遵循 `prefers-reduced-motion`。
